# تطبيق دورات النوم (Android APK Project)

يحتوي هذا المجلد على المشروع الكامل لتطبيق **دورات النوم** للأندرويد مع الشعار المخصص بجميع المقاسات القياسية (`mipmap-mdpi` إلى `mipmap-xxxhdpi`) وملف بناء تلقائي عبر **GitHub Actions**.

## طريقة استخراج ملف `دورات-النوم.apk` تلقائياً عبر GitHub Actions (في دقيقة واحدة)

1. فك الضغط عن هذا الملف (`Dawrat_AlNawm_Android_APK_Project.zip`).
2. ارفع محتوياته إلى مستودع GitHub الخاص بك (مثل مستودع بناء تطبيقات الأندرويد لديك).
3. انتقل إلى تبويب **Actions** في المستودع واضغط على **Build Dawrat Al-Nawm APK (دورات النوم)**.
4. بعد انتهاء البناء تلقائياً، حمّل ملف **`دورات-النوم.apk`** الجاهز للتثبيت مباشرة على هاتفك.

## المكونات المدمجة في الحزمة
- **الاسم الرسمي للتطبيق في النظام:** `دورات النوم` (`com.omar.sleepcycles`)
- **الشعار المعتمد:** مدمج بجميع دقات أندرويد القياسية (`ic_launcher.png` و `ic_launcher_round.png`).
- **الكود الكامل للتطبيق:** مدمج داخل `app/src/main/assets/index.html` مع تفعيل الصوت التفاعلي (Web Audio API) وحفظ الإعدادات محلياً.
